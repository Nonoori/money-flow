Ringkasan Produk (Money Flow)

Aplikasi web mobile-first untuk pencatatan arus kas pribadi & UMKM secara real-time. Mendukung multi-dompet (Tunai, Bank, E-Wallet), transfer antar akun tanpa distorsi omzet, penganggaran bulanan, dan analitik visual.

Spesifikasi Fitur CRUD

  • Transaksi CRUD: Create, Read, Update, Delete untuk Pengeluaran, Pemasukan, dan Transfer antar dompet dengan kalkulasi saldo otomatis.
  • Dompet CRUD: Manajemen akun kas, bank, dan e-wallet lengkap dengan saldo awal & warna identitas.
  • Anggaran (Budget) CRUD: Penetapan limit belanja per kategori dengan indikator peringatan (80% & 100%).
  • Kategori CRUD: Kustomisasi kategori usaha & rumah tangga.
  • Hybrid Persistence: Offline-first via localStorage + Sinkronisasi Cloud ke PostgreSQL via Supabase JS SDK.

Salin & jalankan di Supabase SQL Editor:

-- 1. Tabel Dompet (Wallets)
CREATE TABLE IF NOT EXISTS wallets (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT NOT NULL,
  initial_balance BIGINT DEFAULT 0,
  color TEXT DEFAULT 'indigo',
  icon TEXT DEFAULT 'fa-wallet',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Kategori (Categories)
CREATE TABLE IF NOT EXISTS categories (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT CHECK (type IN ('income', 'expense')),
  icon TEXT NOT NULL,
  color TEXT NOT NULL
);

-- 3. Tabel Anggaran (Budgets)
CREATE TABLE IF NOT EXISTS budgets (
  id TEXT PRIMARY KEY,
  category_id TEXT REFERENCES categories(id) ON DELETE CASCADE,
  limit_amount BIGINT NOT NULL
);

-- 4. Tabel Transaksi (Transactions)
CREATE TABLE IF NOT EXISTS transactions (
  id TEXT PRIMARY KEY,
  type TEXT CHECK (type IN ('income', 'expense', 'transfer')),
  amount BIGINT NOT NULL,
  category_id TEXT,
  wallet_id TEXT REFERENCES wallets(id) ON DELETE CASCADE,
  to_wallet_id TEXT,
  date DATE NOT NULL,
  note TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Langkah 1 — Setup Backend PostgreSQL (Supabase)

Buat proyek gratis di supabase.com, buka menu SQL Editor, lalu jalankan skema SQL dari tab 2. SQL Supabase.

Langkah 2 — Hubungkan Frontend ke Cloud

Masuk ke tab Dompet → Cloud & Data, tempel Project URL dan Anon Public Key, lalu klik Simpan & Push untuk mengunggah data transaksi.

Langkah 3 — Hosting & PWA Mobile

Deploy file tunggal ini ke Vercel, Netlify, atau Cloudflare Pages, lalu buka di browser ponsel dan pilih Add to Home Screen untuk pengalaman aplikasi mobile native.
